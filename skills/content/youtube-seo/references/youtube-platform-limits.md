# YouTube platform limits

The constraints below are the ones that shape the generated document. Check them while writing titles, tags, descriptions, and chapters.

## Titles

- Maximum 100 characters.
- Search results and mobile layouts truncate titles around 60 to 70 characters, so keep the primary keyword in the first half and keep the title short enough to survive truncation.
- The title is the single strongest ranking signal the creator controls. It should contain the exact phrase a viewer would search.

## Description

- Maximum 5,000 characters.
- The first 150 characters (roughly the first two lines) are what search snippets and hover previews show. Front-load the primary keyword and the hook.
- Line breaks are preserved, so a chapter list reads cleanly when pasted in.

## Tags

- Total limit is 500 characters for the entire tags field, commas included.
- Tags carry less weight than the title and description, but they still help with alternate spellings and near-synonyms people search for.
- Each tag does not need to be a single word. Multi-word phrases match how people actually search.

## Chapters

- The first chapter timestamp must be 0:00.
- At least 3 chapters total.
- Each chapter must be at least 10 seconds long.
- Timestamps are entered in the description in `mm:ss` or `hh:mm:ss` form. YouTube treats the first line of a timestamp block as the video's start if it reads as a timecode, so the 0:00 line should be present.
- Chapter titles should be under 70 characters and describe the section, not tease it.

## Hashtags

- Keep to 3 or fewer. The first three hashtags appear above the video title.
- Stacking hashtags in the description reads as spam and dilutes the message.

## Comments

- A pinned comment has the same 5,000-character ceiling as a description, which is far more room than a pinned comment needs.
